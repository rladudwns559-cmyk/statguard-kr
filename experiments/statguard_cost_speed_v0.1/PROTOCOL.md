# 비용·속도 비교 프로토콜 v0.1 (실행 전 고정)

작성: 2026-11-24. API 호출 없음.

## 질문

같은 답변을 검증할 때 StatGuard(LLM 없음)와 LLM 심판은 시간과 비용이 얼마나 다른가?

## 데이터와 방법

- 대상: `statguard_comparison_v0.1`의 답 360개(답변 모델 3종 × 120문항) — LLM 심판이 실제로 판정한 그 답변들.
- **StatGuard:** 이 PC(Windows, Python 3.12)에서 답변마다 CSV 읽기(`load_csv_bytes`) + 규칙 검증(v0.7) + 오류 역추적 + 답변 속 계산 검산을 한 번에 실행한 시간을 `time.perf_counter`로 3회 재고 그 중앙값을 답변의 시간으로 쓴다. 첫 1회 예열 실행은 버린다. API 비용은 0.
- **LLM 심판:** `statguard_comparison_v0.1/results/usage.jsonl`의 gpt-6-luna 심판 호출 기록(시험 실행 포함)에 저장된 응답 시간(`latency_s`)과 토큰 수. 비용은 이 실험들의 사전 고정 단가(입력 $0.10/1M, 출력 $0.50/1M 토큰)로 추정한다(실제 청구액 아님).
- 보고: 답변 하나당 중앙값·95번째 백분위 시간, 답변 1,000개당 추정 비용, 그리고 같은 답 360개에서의 ‘통과 중 오답’(비교 실험 결과 인용).

## 해석 한계

- StatGuard 시간은 이 PC에서의 계산 시간이며 네트워크 왕복은 포함하지 않는다(공개 사이트에서는 서버 왕복이 더해진다). LLM 심판 시간은 OpenAI API 왕복 전체다.
- LLM 단가는 모델·시기에 따라 다르다.
