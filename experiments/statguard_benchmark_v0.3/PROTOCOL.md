# StatGuard-KR 도메인 확장(v0.3) · 반복 실행 프로토콜 (실행 전 고정)

작성: 2026-11-20.

## A. 도메인 확장 벤치마크 v0.3 (RQ4)

v0.1(기상·환경·인구·합성, 작은 표)과 v0.2(기상, 큰 표)에 이어 **인구·경제·보건 도메인의 국가별 표**로 같은 비교를 한다.

- 자료: World Bank WDI 2023, 176개국(지역 묶음·미분류 79개, 결측 41개 제외), 열: 국가·국가코드·지역(7)·소득그룹(4)·총인구·실업률·1인당GDP·기대수명. 1인당GDP는 소수 2자리, 실업률·기대수명은 3자리로 반올림(엔진 입력 한도 6자리). `build_datasets.py`, `datasets_report.json`.
- 질문 22개: 답변 가능 19(합계·평균·중앙값·최댓값·최솟값·표준편차·상관계수·t 통계량·p값·비율·국가코드 조회), 답변 불가 3(자료 밖 연도, 결측으로 제외된 국가, 원인 해석).
- 기대값: v0.2와 같은 독립 계산(분수·Decimal 50자리, p값 수치적분), 30자리 저장.
- 조건 A·B·C, LLM 추출(A), 오류 주입 세트: v0.2와 동일. 정답 단위 동의어에 USD·$·미국 달러 → 달러, 살 → 세 추가.
- 제안 방법: 규칙 추출 **v0.6**(실행 전 고정, SHA-256 `edefeeae…`, `frozen/claims_v0_6.py`). v0.6은 이 자료의 예시 문장(모델 답변 아님)으로 점검해 열 이름 속 숫자(“1인당GDP”의 1)와 앞 문장 범위 상속 조건을 고친 버전이다. 이 실행 결과를 본 뒤 고치면 v0.7로 분리한다.

## B. 반복 실행 (안정성)

- 대상: v0.1 본 세트, v0.2 본 세트, v0.3 본 세트의 **A(일반 LLM)와 C(계산 도구)** 조건.
- 같은 요청을 2회 더(총 3회) 실행한다. 모델·지시문·입력은 1회차와 바이트 단위로 같고, 캐시 키만 회차별로 다르다(`STATGUARD_REPEAT`). 결과 파일 `answers_A_r2.json` 등.
- 보고: 회차별 정답률, 문항별로 3회 정답이 일치한 비율, StatGuard(모든 벤치마크에 같은 규칙 추출 v0.6 고정 사본을 적용해 회차 간 차이만 보이게 함) 통과 답변의 오답률과 판정 비율의 회차별 값. LLM 추출은 1회차만.
- 호출 상한: v0.2 폴더는 반복분을 위해 700회로 올린다(1회차 263회 사용). v0.1 폴더는 3회차 도중 400회 상한에 걸려 600회로 올리고 남은 문항만 이어서 실행했다(이미 받은 응답은 캐시로 재사용, 추가 호출 없음). 예상 추가 비용 약 $0.5~0.7(사전 고정 단가 기준).

## 해석 한계

- 반복 3회는 변동의 크기를 보여주는 정도이며 신뢰구간을 주장하지 않는다.
- 국가 이름은 영어 원문이라 한국어 답변에서 국가를 지목하면 규칙 추출이 보류할 수 있다(국가코드 질문으로 보완).
