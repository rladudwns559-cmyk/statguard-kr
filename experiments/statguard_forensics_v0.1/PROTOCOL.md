# StatGuard 오류 역추적 검증 프로토콜 v0.1 (실행 전 고정)

작성: 2026-11-24. 역추적 모듈(`src/when2warn/statguard/forensics.py`, statguard-forensics-v0.1)을 평가하기 전에 작성했다. API 호출은 없다(전부 결정적 계산).

## 1. 질문

1. **재현율:** 알려진 계산 실수로 만든 틀린 숫자를 주면, 역추적이 그 실수를 찾는가?
2. **헛설명률:** 이유 없이 틀린(무작위) 숫자를 주면, 역추적이 억지로 설명을 붙이는 비율은 얼마인가? (낮을수록 믿을 만함)
3. **실제 오답:** 실험에서 실제 LLM이 틀려 StatGuard가 ‘계산 불일치’로 잡은 주장 중 몇 건의 원인을 재현하는가?

## 2. 기본 주장

기존 벤치마크 v0.1·v0.2·v0.3의 조건 A(gpt-6-luna) 답변 120개를 규칙 추출기 v0.7로 검증해, ‘계산 일치’로 확인된 주장 중 **2행 이상을 쓰는 계산**(합계·평균·표준편차·분산·중앙값·최댓값·최솟값)만 쓴다. 주장의 문장·계산 범위·허용 오차(답변 자릿수 기준)는 그대로 두고 숫자만 바꾼다.

## 3. 주입하는 실수 (각 기본 주장에 적용 가능한 것만)

| 종류 | 만드는 방법 | 정답으로 인정하는 진단 |
|---|---|---|
| 행 하나 누락 | 계산 범위에서 무작위 1행을 빼고 같은 계산 (기본 주장당 최대 5회, 서로 다른 행) | OMITTED_ROW이고 진단의 행 목록에 뺀 행이 포함 |
| 다른 통계량 | 평균↔중앙값, 합계→평균, 표준편차↔분산 | WRONG_STATISTIC |
| 개수 잘못 셈 | 평균에서 n−1로 나눔 | WRONG_COUNT |
| 자릿수 오류 | 올바른 값 × 10 | SCALE |
| 다른 열 | 같은 계산을 다른 숫자 열에 (열이 있을 때) | WRONG_COLUMN |

- 바꾼 숫자는 원래 답변의 자릿수로 반올림한다. 반올림 후 올바른 값과 허용 오차 안이면(= 불일치가 아니면) 그 경우는 제외한다.
- 진단이 주입한 종류와 다르지만 같은 숫자를 재현한 경우는 ‘다른 설명’으로 따로 센다(틀린 설명은 아니지만 정답으로 세지 않음).

## 4. 무작위 숫자 (헛설명률)

기본 주장마다 올바른 값에 (1 + u)를 곱한 값을 10개 만든다. u는 ±[1%, 20%]에서 균등(부호 무작위), 원래 자릿수로 반올림. 역추적이 어떤 설명이든 붙이면 ‘헛설명’으로 센다. 무작위 시드 20261124.

## 5. 실제 오답

벤치마크 조건 A 답변 120개와, `statguard_comparison_v0.1`에서 새로 받은 다른 모델의 답변(실행된 만큼)에서 ‘계산 불일치’로 잡힌 주장 전부에 역추적을 적용해, 설명을 붙인 건수와 내용을 그대로 보고한다(정답 원인을 알 수 없으므로 재현 여부만 보고).

## 6. 해석 한계

- 주입 실수는 역추적이 찾는 목록과 같은 종류이므로 재현율은 ‘목록 안의 실수를 놓치지 않는가’를 본다. 목록 밖의 실수(예: 엉뚱한 암산)는 원래 찾을 수 없다.
- 무작위 숫자는 실제 LLM 오답의 분포와 다르다. 헛설명률은 우연히 맞아떨어지는 정도의 참고치다.

## 변경 기록

- 2026-11-24, 첫 실행 후: 첫 실행(시드 20261124)에서 무작위 숫자 316개 중 22개(7.0%)에 설명이 붙었고 그중 11개가 ‘확신 높음’이었다. 원인은 작은 표에서 ‘행 하나 누락’ 같은 후보가 많아 무작위 숫자와 우연히 맞는 것이었다. 그래서 모듈에 **우연 일치 확률**(후보 값들이 올바른 값 ±20% 구간을 덮는 비율)을 넣어, 0.05 미만이고 후보가 하나일 때만 ‘확신 높음’, 기준값 이상이면 설명을 내지 않게 바꿨다(답변이 스스로 그 개수를 적은 경우는 예외).
- 기준값은 같은 시드에서 0.5·0.25·0.1을 비교해 0.25로 정했다(주입 실수 재현 167/181, 무작위 헛설명 16/316). **같은 데이터로 기준을 고른 것이므로**, 최종 결과는 기준을 고정한 뒤 처음 쓰는 새 시드 **20261201**로 다시 실행한 값을 보고한다(`python -X utf8 -I run_eval.py 20261201`). 실제 오답(5장)은 시드와 무관하다.
