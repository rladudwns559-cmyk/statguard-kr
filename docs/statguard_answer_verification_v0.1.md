# StatGuard-KR AI 답변 검증·벤치마크 v0.1 (2026-11-20)

이전 단계(`statguard_real_csv_review_v0.1`, 2026-10-23)까지는 CSV 계산과 **사람이 입력한** 수치 비교만 있었다. 이번 단계에서 신청서·수정일정의 P0인 “주장 추출 → 재계산 → 4상태 판정·보류”와 일반 LLM 비교 실험을 구현·실행했다.

## 1. 구현한 것

| 구분 | 내용 | 위치 |
|---|---|---|
| 규칙 기반 주장 추출 v0.3 | 한국어 문장에서 수치·단위·열·조건(지역·연도·연월·월)·연산(합계·평균·증감률·비율·값 조회)을 찾아 계산 사양으로 연결. ‘대비/보다/에서~로/전년’ 기준 시점, ‘약·만·억’, 감소 부호, 기간 범위, 수식 속 숫자 처리 | `src/when2warn/statguard/claims.py` |
| 4상태 판정 | 답변 자릿수 기준 반올림 허용(±0.5×10^-자릿수). 단위 불일치·열 모호·기준 시점 불명·자료 밖 기간·미지원 통계·해석 문장은 보류(사유 코드 20여 종) | 같은 파일 `verify_claim` |
| LLM 주장 추출기 | gpt-6-luna 구조화 출력(JSON schema strict). 모델은 ‘어떤 계산인지’만 제안하고 값은 엔진이 계산. 목록에 없는 열·값이면 보류 | `llm_extractor.py` |
| 연결 | `verify_answer` 모드 추가(로컬·Vercel 공통, 원본 bytes·미리보기 해시 재검증) | `local_bridge.py`, `frontend/api/statguard.py` |
| 화면 | ‘AI 답변 검증’ 탭: 단위 확인 → 답변 붙여넣기 → 주장별 판정 카드(답변 수치·재계산·차이·사유·계산식·사용한 행). 실제 공개 자료 예시 4종 원클릭. `/statguard/results` 실험 결과 페이지 | `frontend/src/statguard/` |

웹 화면은 LLM API를 호출하지 않는다. LLM 추출기는 실험에서만 사용했다.

## 2. 벤치마크

- 자료 5종(NOAA 강수량·CO₂, World Bank 대한민국 총인구 2종·실업률, 합성 1종). World Bank 2014~2023 자료는 2026-11-20 API로 새로 받았다(갱신일 2026-11-11, CC BY 4.0).
- 본 세트 36문항(답변 불가 9), 별도 검증 세트 18문항. 기대값은 엔진과 별도의 분수 계산.
- 조건: A 일반 LLM(CSV만), B +자료 설명, C +계산 도구(엔진을 함수 도구로 호출), 제안 방법(A·B·C 답변에 StatGuard 적용).
- 모델 gpt-6-luna 1종, 질문당 1회, 응답 캐시. 호출 272회, 토큰 입력 126,726 / 출력 44,584, 추정 $0.035(사전 고정 단가 기준, 청구액 아님).

# 추가 단계: 통계 연산 · 큰 표 벤치마크 v0.2 · 시연 모드 (2026-11-20)

## 통계 연산 (계산 엔진·추출기 v0.4)

- 엔진: 표준편차·분산(표본 n−1과 모집단 값을 함께 계산), 중앙값, 최댓값·최솟값(해당 행 기록), 피어슨 상관계수(두 열), Welch 두 집단 t-검정(양측 p값, float64 근사). 기존 연산의 계산 사양·식별값은 바뀌지 않음(추가 필드는 새 연산에서만 출력).
- 검산: Python `statistics`, 독립 수치적분(p값 차이 < 1e-12)과 비교.
- 추출·판정: 표준편차 주장은 표본·모집단 중 일치하는 정의를 표시, “가장 많았다”는 값과 지목한 행을 함께 확인, t-검정은 유의성(α=0.05)·p값·부등식(p<0.05)·t값을 판정. 회귀·추세·“지역별” 집단 통계처럼 의미가 모호하면 보류.
- LLM 추출기 v0.2도 같은 연산을 구조화 출력으로 제안.

## 큰 표 벤치마크 v0.2 (`experiments/statguard_benchmark_v0.2/`)

- 자료: NOAA GHCN-Daily 2023 시애틀 일별 365행, 미국 4개 도시 1,460행(일별 합이 월별 공식값 12개와 모두 일치 확인). World Bank 국가별 자료는 실행 시점 API 502로 제외.
- 본 세트 30문항 + 별도 검증 14문항, 조건 A·B·C, 호출 263회·추정 $0.33.
- 결과: 정답률 A 20/30 · B 18/30 · C 29/30. StatGuard가 통과시킨 답변의 오답 0건(모든 조건·추출 방식). 실행 전 고정한 규칙 v0.4는 A에서 오류 표시 6건 중 오탐 2건 → 이를 고친 v0.5는 별도 검증 세트에서 오탐 0건(v0.4는 같은 세트 오탐 2건). LLM 추출기는 별도 검증 세트에서 오탐 2/4.
- 정정 기록: 기대값을 12자리로 저장해 계산 도구 답변(15자리)을 오답 처리한 채점 오류를 30자리 저장으로 고침(판정 규칙 불변). 출력 한도로 끝나지 않은 답변 6건(A·B)은 사전 규칙대로 형식 오류.

## 규칙 추출 v0.5 (웹 적용)

“모두 합한/합하면” 합계, “연간 합계의 x%” 비율, 중복되는 마지막 ‘최종값’ 줄, 조건부 개수(“0mm보다 큰 날”) 보류, 앞 문장의 대상을 이어받는 문장 보류, “n−1” 같은 수식 숫자 무시, “최댓값”은 범위·“가장”은 지목 행으로 구분, 날짜 열에 없는 연도 감지. 각 버전 사본과 해시는 `experiments/*/frozen/`에 보관.

## 시연 모드 (로컬 전용)

`node scripts/statguard-local.mjs --live --live-env-file <키 파일>`로 켜면 화면에 ‘AI에게 직접 질문’ 상자가 생겨 질문 → gpt-6-luna 답변(벤치마크 A와 같은 지시문) → 즉시 검증. 실행당 30회 제한, 키는 질문 처리 하위 프로세스에만 전달, Vercel 배포 경로에는 없음. 브라우저에서 실제 1회 호출로 동작 확인.

## 검증

Python StatGuard 테스트 174개, 프론트엔드 237개(`--maxWorkers=2`, 기본 병렬 실행 시 부하로 5초 제한을 넘는 테스트가 있어 줄여서 실행), 실행기 라우트 16개, 타입 검사·빌드 통과. 공개 사이트 재배포와 GitHub 업로드는 아직 하지 않음.
