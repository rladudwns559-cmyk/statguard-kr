# StatGuard 실제 공개 CSV 3종 점검

## 결과

기존 화면·계산 엔진을 변경하지 않고 공개 자료 3종의 정리본을 업로드해 계산·식·단위·사용 행·수치 비교를 확인했다. 실제 Edge와 로컬 Python 계산 엔진을 사용했으며 mock 결과로 대체하지 않았다.

| 시애틀 2023 월별 강수량 12행 | 합계 888.9 mm | 정확히 일치 | 1000과 불일치, 차이 111.1 mm |

평균은 12개 공개 월평균의 산술평균이며 NOAA 공식 연평균을 재현했다고 주장하지 않는다. 인구 증감률은 이 두 연도의 총인구 추정치로 계산한 파생값이다. 강수량도 공개된 월별 합계 12개의 합이며 원관측의 완전성까지 검증한 것은 아니다.

## 검증 방법과 실제 실행

공개 공식 URL에서 작은 원본 3건(787 / 38,776 / 1,860 bytes)을 확보하고 원본·해시를 보존했다. World Bank ZIP은 본표와 메타데이터를 파일명 검증 후 추출했다. 원자료의 숫자 26개를 그대로 보존한 한국어 정리본을 만들었다. 실제 개인정보·사람별 행은 없다.

기대값은 제품 모듈을 import하지 않는 Python 표준 Fraction으로 원본 셀에서 계산했다. 소수 표시에만 Decimal을 사용했다. 파일·기대값·입력·허용 차이는 브라우저 실행 전에 해시로 고정했다. 평균·증감률의 반올림 입력은 소수 6자리, 허용 차이 0.000001로 사전 고정했다. 독립 분수값과 엔진 출력의 수치 오차는 각각 1e-30 이하로 확인했다. 이 수치 오차 한계는 측정 정확도나 제품의 사용자 허용 차이와 다르다.

최종 브라우저 검사 51개 모두 통과. 계산 3회·비교 6회(안내용 3회와 추가 통제 3회) 실행. 강수량 888.9의 정확 일치, 평균의 허용 차이를 0으로 바꾼 경우 불일치, 인구 입력을 1로 바꾼 경우 불일치도 확인했다. 식·출력 단위·실제 선택 및 기준 행·화면 표·자료 비우기·메모리 상태 비보존을 점검했다. 브라우저의 외부 요청 시도 및 JavaScript 오류는 0이다.

제품 계산값을 기준값으로 복사해서 비교한 것이 아니다. 원본 셀→정리본 값 26개 대응, 원본/정리본 해시, 사전 manifest 무결성을 별도로 확인했다. 자동 브라우저 실행은 개발 점검이며 처음 쓰는 사람의 관찰 결과가 아니다.

## 남은 확인과 범위

실제 처음 쓰는 참여자 1명의 사용성 확인은 아직 미실시다. 참가자 수·성공률·사용 시간·연구 정확도를 보고하지 않는다. 공개 실자료의 계산 확인 완료와 신규 사용자 검증 완료를 구분한다. 화면은 반복소수의 34자리 값을 길게 보여주므로 안내에 읽는 법을 설명했다. 이번에는 표시 방식도 수정하지 않았다.

제품 source·테스트·설정·기존 보고서를 모두 그대로 두고 신규 자료·분석 도구·문서만 추가했다. 기존 기준 1,071파일의 SHA-256 불변을 설치 시 다시 확인한다. 소스 변경이 없으므로 이전 단계의 365개 회귀검사를 신규 통과 건수로 다시 세지 않고, 이번 51개 브라우저 검사와 독립 계산 3건만 보고한다. 전체 과거 evaluator/backend suite는 이번에 실행하지 않았다.
