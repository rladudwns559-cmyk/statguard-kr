# 실제 CSV 계산 확인표 — 관찰자용

처음 쓰는 참여자에게는 따라하기 안내와 빈 점검 기록지를 제공합니다. 이 문서는 개발 점검의 독립 계산값이며 참여자의 실제 사용 기록을 대신하지 않습니다.

| 연습 | 기준 계산값 | 안내의 입력 | 허용 차이 | 기대 비교 |
|---|---|---|---|---|
| 1 강수량 합계 | 888.9 mm | 1000 | 0 | 불일치, 입력이 111.1 mm 높음 |
| 2 월평균 CO₂ 값의 산술평균 | 424.604166666… ppm | 424.604167 | 0.000001 ppm | 허용 차이 이내. 정확히 같은 값은 아님 |
| 3 총인구 증감률 | 0.077507274701… % | 0.077507 | 0.000001 퍼센트포인트 | 허용 차이 이내. 정확히 같은 값은 아님 |

연습 1의 공개 값 합계: 78.5 + 60.1 + 65.3 + 98.1 + 23.8 + 31.0 + 2.3 + 6.8 + 87.3 + 73.3 + 147.0 + 215.4 = 888.9.

연습 2는 원본 `average` 열의 2024년 12개 값 합계 5095.25 ÷ 12다. 공식 발표 연평균 또는 관측일수 가중평균과의 비교가 아니다. 사용 행은 1~12다.

연습 3은 (51,712,619 - 51,672,569) ÷ 51,672,569 × 100이다. 현재 2023년은 데이터 2행, 기준 2022년은 데이터 1행이다. 총인구 추정치의 이 스냅샷으로 계산한 값이며 별도 공식 인구증가율 지표와 같다고 가정하지 않는다.

허용 차이는 자료를 보기 전에 고정한 반올림 비교 조건이다. 차이가 난다고 결과를 맞추기 위해 임의로 늘리지 않는다. 화면은 34자리 계산 결과를 길게 보여줄 수 있으며 위 생략 표기는 읽기용이다.

관찰자는 먼저 혼자 진행하게 하고 도움 요청 시 어느 단계에서 무엇을 알려줬는지 기록한다. 틀린 조작을 개발자 자동 점검의 성공 기록으로 덮어쓰지 않는다. 실제 사용이 끝나기 전에는 참가자 수·성공 여부를 채우지 않는다.
