# StatGuard 처음 사용하기

CSV에서 숫자를 계산하고, 직접 입력한 수치와 얼마나 다른지 확인하는 연습입니다. 세 자료의 숫자는 공개 원본에서 가져왔으며, 읽기 쉽게 한국어 열 이름으로 정리했습니다. 개인별 기록은 없습니다.

## 시작 전

1. 개발 담당자가 계산 화면을 실행한 이 PC에서 진행합니다. 다른 PC에서는 아래 주소가 저절로 열리지 않습니다.
2. [StatGuard 계산 화면](http://127.0.0.1:5173/statguard)을 새 탭으로 엽니다. 로그인·API 키·결제는 필요하지 않습니다.
3. 이 안내와 같은 묶음의 CSV 폴더를 엽니다. ZIP을 받았다면 먼저 ‘모두 압축 풀기’를 누릅니다. CSV를 Excel에서 다시 저장할 필요는 없습니다.
4. 점검 기록지에 날짜·시작 시각·참가자 코드만 적습니다. 이름·이메일·비밀번호는 적지 않습니다.

안내를 읽어도 막히면 관찰자에게 도움을 요청해도 됩니다. 어느 단계에서 도움을 받았는지 기록합니다. 처음 쓰는 사람이 안내만으로 따라갈 수 있는지 확인하는 과정이며, 참여자의 능력을 평가하는 시험이 아닙니다.

## 연습 1. 시애틀의 월별 강수량 합계

질문: 공개된 2023년 12개월의 강수량을 모두 더하면 얼마이며, 1,000mm와 얼마나 다른가요?

1. ‘CSV 파일 선택’을 눌러 `01_시애틀_2023_월별강수량.csv`를 선택합니다. 원본 보관용 raw 폴더의 파일은 선택하지 않습니다.
2. ‘현재 자료’에 같은 이름이 보이는지 확인합니다. 데이터는 12행이며 미리보기는 처음 10행까지만 보일 수 있습니다.
3. ‘계산 종류’는 `합계`, ‘계산할 숫자 열’은 `강수량`, ‘열의 원래 단위’는 `mm`로 입력합니다.
4. ‘선택 범위’에는 조건을 추가하지 않습니다. 전체 12행을 사용합니다. ‘빈 숫자 값 처리’는 기본값인 중단으로 둡니다.
5. 열·단위·범위 확인란을 체크하고 ‘이 조건으로 확인’을 누른 뒤 ‘계산 실행’을 누릅니다.
6. 계산 결과, 실제 계산식, ‘사용한 행 (12)’을 찾아봅니다. 사용한 행 표에는 11·12행도 보입니다.
7. ‘비교할 수치 (mm)’에 `1000`을 입력하고 ‘수치 비교’를 누릅니다. 허용 차이는 기본값 `0`으로 둡니다.
8. 결과값·비교 판정·절대 차이를 점검 기록지에 적습니다.

## 연습 2. 월별 CO₂ 값의 산술평균

질문: 마우나로아의 2024년 월평균 CO₂ 값 12개를 같은 비중으로 평균 내고, 반올림한 수치와 비교해 보세요.

1. 같은 화면에서 `02_마우나로아_2024_월별CO2.csv`를 새로 선택합니다. 이전 계산 결과가 사라지고 현재 자료 이름이 바뀌는지 확인합니다.
2. ‘계산 종류’는 `평균`, 숫자 열은 `이산화탄소농도`, 원래 단위는 `ppm`으로 입력합니다. 선택 범위 조건은 추가하지 않습니다.
3. 확인란 → ‘이 조건으로 확인’ → ‘계산 실행’ 순서로 누릅니다.
4. 결과의 소수점 이하가 길어도 오류라는 뜻은 아닙니다. 사용한 행은 12행인지 확인합니다.
5. 비교할 수치에 `424.604167`을 입력합니다. ‘허용 차이 설정’을 펼쳐 ‘허용 차이 (절대값)’에 `0.000001`을 입력한 뒤 ‘수치 비교’를 누릅니다.
6. 결과값·비교 판정·차이를 기록합니다. 이 허용 차이는 소수점 6자리로 반올림한 수치를 비교하기 위해 정한 값이며 원자료의 측정 불확실성과는 다릅니다.

여기서 구하는 값은 12개 월평균의 단순 산술평균입니다. 날짜 수로 가중한 평균이나 NOAA가 별도로 발표하는 연평균과 같다고 해석하지 않습니다.

## 연습 3. 대한민국 총인구 증감률

질문: World Bank 자료의 2022년 총인구를 기준으로 2023년 총인구는 몇 % 변했나요?

1. `03_대한민국_2022_2023_총인구.csv`를 선택합니다. 미리보기의 연도는 2022·2023, 데이터는 2행입니다.
2. ‘계산 종류’는 `증감률`, 숫자 열은 `총인구`, 원래 단위는 `명`으로 입력합니다. 결과 단위는 자동으로 %가 됩니다.
3. ‘+ 선택 범위 조건 추가’를 누릅니다. ‘선택 범위 1 열’은 `연도`, ‘선택 범위 1 값’은 `2023`으로 입력합니다. 선택 범위는 비교할 현재 시점입니다.
4. ‘+ 기준 범위 조건 추가’를 누릅니다. ‘기준 범위 1 열’은 `연도`, ‘기준 범위 1 값’은 `2022`로 입력합니다. 기준 범위는 출발 시점입니다.
5. 선택 범위와 기준 범위가 각각 1행인지 확인합니다. 확인란 → ‘이 조건으로 확인’ → ‘계산 실행’을 누릅니다.
6. 식이 `(2023년 인구 - 2022년 인구) / 2022년 인구 × 100`의 순서인지 확인합니다. 선택의 사용 행은 2행, 기준의 사용 행은 1행입니다.
7. 비교할 수치에 `0.077507`을 입력하고, ‘허용 차이 설정’의 절대값을 `0.000001`로 설정한 뒤 ‘수치 비교’를 누릅니다. 숫자 뒤에 %를 직접 붙이지 않습니다.
8. 결과값·비교 판정·차이를 기록합니다. 퍼센트 값 둘의 절대 차이 단위는 ‘퍼센트포인트’입니다.

이 자료의 총인구는 연도별 집계 추정치입니다. 두 연도의 인구를 합계내는 것이 아니라 서로 다른 기준·현재 범위로 비교합니다.

## 막혔을 때

| 상황 | 다음 행동 |
|---|---|
| 사이트에 연결할 수 없음 | 개발 담당자에게 로컬 계산 화면을 다시 실행해 달라고 요청합니다. 이 점검을 위해 새 결제나 배포를 하지 않습니다. |
| 글자가 깨짐 | 지정한 한국어 정리본 파일인지 확인하고 문자 인코딩을 자동 감지로 둡니다. 계속 깨지면 화면 문구와 단계를 기록하고 도움을 요청합니다. |
| 확인 버튼이 비활성 | 숫자 열·단위와 ‘아래 조건을 확인해 주세요’ 안내를 확인합니다. 증감률에서는 선택·기준 연도를 구분합니다. |
| 조건 변경 후 결과가 사라짐 | 정상 동작입니다. 이전 조건의 결과를 사용하지 않도록 다시 확인·계산합니다. |
| 정확히 일치하지 않음 | 입력값과 허용 차이를 확인합니다. 연습 2·3은 반올림한 값을 비교하므로 안내의 허용 차이를 사용합니다. |
| 새로고침하려는 경우 | 현재 작업은 저장되지 않습니다. 기록지에 먼저 적고, 새로고침 후에는 파일부터 다시 선택합니다. |

## 마친 뒤

점검 기록지의 세 연습을 채우고, 가장 헷갈린 부분을 한 문장으로 적습니다. 마지막으로 ‘자료 비우기’를 눌러 계산 결과가 없어지는지 확인합니다. 별도 제출·서버 저장 버튼은 없습니다. 이 단계에서 GPT나 외부 서비스로 CSV를 보내지 않습니다.
