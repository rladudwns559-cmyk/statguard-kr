# 학술대회 발표 수치 정리 v0.1

발표 슬라이드에 쓰는 숫자를 한곳에 모았다. 모든 비율에 분모를 함께 적고, 0건이면 95% 상한을, 비교에는 p값을 붙인다.
출처는 각 실험의 `results/REPORT.md`(저장된 응답으로 재계산, API 호출 없음)이다.
95% 상한은 Clopper–Pearson 양측, p값은 Fisher 정확검정 양측이다. 검정은 PROTOCOL에 없던 사후 계산이다.

## 1. 문제: 표가 커지면 일반 LLM이 틀린다 (gpt-6-luna, 1회차 본 세트)

| 벤치마크 | A 일반 LLM | B +자료 설명 | C +계산 도구 |
|---|---|---|---|
| 작은 표 (2~12행) | 33/36 (91.7%) | 33/36 (91.7%) | 36/36 (100%) |
| 큰 표 (365·1,460행) | 20/30 (66.7%) | 18/30 (60.0%) | 29/30 (96.7%) |
| 국가별 (176행) | 12/22 (54.5%) | 13/22 (59.1%) | 21/22 (95.5%) |

- 큰 표 A 오답 10건 중 3건, 국가별 A 오답 10건 중 6건은 출력 길이 제한으로 답을 끝내지 못한 경우다.

## 2. 핵심 비교: LLM 심판 대 StatGuard (답변 모델 3종 × 120문항 = 답 360개, 실제 오답 133개)

| 방식 | 통과 | 통과 비율 | 통과 중 오답 | 95% 상한 | 오답 중 지적 | 보류 |
|---|---|---|---|---|---|---|
| LLM 심판 gpt-6-luna | 235 | 65.3% | 13 (5.5%) | 9.3% | 109/133 (82%) | 11 |
| StatGuard 사전 등록 규칙 | 105 | 29.2% | 1 (1.0%) | 5.2% | 49/133 (37%) | 197 |
| StatGuard 최종값 규칙 (사후 탐색) | 90 | 25.0% | 0 | 4.0% | 49/133 (37%) | – |
| 결합: 최종값 규칙 → 보류분만 LLM 심판 (사후 탐색) | 224 | 62.2% | 7 (3.1%) | 6.3% | 115/133 (86%) | – |

| 비교 (통과 중 오답) | p (양측) | 쓸 수 있는 표현 |
|---|---|---|
| 사전 등록 규칙 1/105 대 심판 13/235 | 0.072 | “적은 경향(유의하지 않음)” |
| 최종값 규칙 0/90 대 심판 13/235 | 0.023 | “사후 규칙에서 유의, 새 답변 확인 필요” |
| 결합 7/224 대 심판 13/235 | 0.26 | “차이 없음” |
| gpt-6-luna 88문항: StatGuard 0/35 대 심판 8/71 | 0.050 | “경계선” |

- 한쪽 검정(p = 0.038)은 사전에 정하지 않았으므로 쓰지 않는다.
- LLM 심판은 자기 답(gpt-6-luna) 120개도 채점했고(그중 99개 통과), 통과 중 오답 13건 중 9건이 자기 답이었다.
- 자기 일관성(3회 같은 답이면 통과, gpt-6-luna 88문항): 통과 53, 통과 중 오답 0.

## 3. 반복 실행 (gpt-6-luna, 세 벤치마크 A·C × 3회)

- StatGuard 통과 279건 중 오답 0건, 95% 상한 1.3%. 반복을 뺀 1회차 93건 기준 상한 3.9%.
- 1회차 본 세트 A 실제 오답 23건: 계산 불일치 6건, 보류 17건, 통과 0건. 통과 279건 중 107건이 A 답변.
- 짧은 답변 위주다. 긴 답변(비교 실험의 교정 후 답)에서는 사전 등록 규칙 통과 중 오답이 gpt-4o-mini 7건, gpt-5-mini 4건 나왔다.

## 4. 근거로 교정 (비교 실험, 1회차 기준)

| 답변 모델 | 원래 정답률 | 재계산 근거로 교정 | 단순 재확인(대조군) | 계산 불일치 오답 중 고침 |
|---|---|---|---|---|
| gpt-4o-mini | 53/120 (44.2%) | 82/120 (68.3%) | 55/120 (45.8%) | 29/34 (대조군 1/34) |
| gpt-5-mini | 81/120 (67.5%) | 83/120 (69.2%) | 81/120 (67.5%) | 2/7 (대조군 0/7) |

- 마지막 열은 계산 불일치로 잡힌 답 중 실제 오답만 센 값이다(정정 2026-11-26: 이전 29/35·10/15는 원래 정답이 섞인 값). gpt-5-mini는 불일치 15건 중 8건이 원래 정답이었다.
- gpt-5-mini는 고친 답 5건, 틀리게 바꾼 답 3건이고 2회차 정답률은 67.5%로 돌아갔다. “약한 모델에서 효과가 크고 강한 모델에서는 작다”로 쓴다.

## 5. 부가 기능

| 항목 | 수치 | 주의 |

| 계산식 검산 (CSV 없이) | ‘계산 틀림’ 100개 중 실제 오답 94개 | 오답 501개 중 검출 94개(18.8%) |

## 6. 쓰면 안 되는 표현

- “StatGuard가 LLM 심판보다 오류를 더 잘 찾는다” → 지적은 37% 대 82%로 오히려 적다. “통과시킨 답의 오답이 적다”가 맞다.
- “통과한 답은 오답 0건” (단서 없이) → 비교 실험 사전 등록 규칙에서 1건, 긴 교정 답변에서 11건이 있었다.
- “유의하게 낮다” → 사전 등록 비교는 p = 0.072.
- “여러 회사 모델에서 검증” → 답변·심판 모두 OpenAI.
- “한국 통계 자료” → 자료는 NOAA·World Bank다.

## 재계산

```python
from scipy.stats import beta, fisher_exact
up = lambda k, n: beta.ppf(0.975, k + 1, n - k)
print(up(1, 105), up(13, 235), up(0, 279))            # 0.052, 0.093, 0.013
print(fisher_exact([[1, 104], [13, 222]]).pvalue)     # 0.072
print(fisher_exact([[0, 90], [13, 222]]).pvalue)      # 0.023
```
