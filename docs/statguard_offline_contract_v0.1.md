# StatGuard 계산 계약 v0.1

이번 범위는 업로드 서버나 GPT 호출이 아닌, bytes 입력 CSV adapter와 독립 계산 core다. 합성 개발 사례이며 정식 benchmark가 아니다.

- CSV: UTF-8/BOM 또는 CP949, 최대 1 MiB, 10,000행, 64열, 셀 512자. 빈/중복/앞뒤 공백 header와 행 폭 불일치는 거부한다. 원래 열·행 순서와 문자열 필터 값을 보존한다.
- 숫자: 명시한 열만 파싱한다. 정수부 최대 18자리·소수부 최대 6자리. NaN/Infinity, 수식, 잘못된 천 단위 구분, 단위·퍼센트가 붙은 셀은 추측하여 변환하지 않는다. 산술은 Decimal precision 34의 ROUND_HALF_EVEN이다.
- 누락: 빈 숫자 셀은 기본 거부. 명시적으로 omit을 선택한 경우만 제외하고 수를 기록한다. 비숫자는 omit으로 숨기지 않는다.
- sum/mean: 명시한 열과 정확히 일치하는 문자열 필터를 사용한다. 빈 선택은 오류다.
- ratio_percent: 현재 선택 합계 / reference 선택 합계 * 100. 참조 선택과 단위는 명시해야 한다. 분모 0은 거부한다. 자동으로 점유율이나 증감률로 해석하지 않는다.
- percent_change: (현재 합계 - 기준 합계) / 기준 합계 * 100. 기준은 양수여야 하며 현재와 기준의 행이 겹치면 거부한다.
- grouped_aggregate: 명시한 group_by별 sum/mean. 빈 그룹키는 거부한다. 그룹은 문자열 정렬한다.
- rank: 그룹별 sum의 내림차순 dense rank. 동률은 같은 순위, 출력 순서만 그룹명으로 고정한다.
- 계산 근거는 데이터 hash, 사양 hash, 사용 행 번호·누락 수·단위·식을 연결한다. 단위는 외부에서 명시하며 수치로 추론하지 않는다.
- 수치 주장 비교는 데이터·계산 연결과 단위가 확인된 scalar 결과만 수행한다. tolerance를 명시하고 일치/불일치를 판정한다. 연결 불명·단위 미확인은 근거 부족이다. 인과 해석·신뢰도 보정은 제공하지 않는다.
- 기존 Agent RuntimeEvidence, 웹 근거·evaluator, API/DB/UI/production과 연결하지 않는다.
