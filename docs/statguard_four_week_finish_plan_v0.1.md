# WHEN2WARN StatGuard 4주 마감 계획

마감 목표는 **CSV 한 개를 읽고, 계산 조건을 확인하고, 재현 가능한 수치 결과와 사용한 행을 보여주는 작은 프로그램**이다. 기존 WHEN2WARN의 로그인·답변 검증·기록 화면은 보존한다. 이 기간에 모든 Agent 연구 기능과 통계 검증 제품을 동시에 완성하는 목표는 잡지 않는다.

## 완료 범위

| 작업 | 현재 상태 | 완료로 볼 기준 |
| --- | --- | --- |
| CSV 입력·미리보기 | 이번 단계 완료 | UTF-8·CP949 예제, 제한·오류 안내, 원문 표 표시 |
| 계산 조건 확인 | 이번 단계 완료 | 합계·평균·증감률의 열·단위·범위·빈 값 정책 확인, 변경 시 확인 해제 |
| 기존 계산 코어 연결 | 다음 한 단계 | 확인한 같은 bytes·조건을 코어에서 재검증하고 값·식·사용 행 표시 |
| 수동 수치 주장 비교 | 후속 최소 범위 | 사용자가 입력한 수치와 계산 결과를 명시적 단위·허용오차 안에서 비교 |
| 최종 품질 정리 | 예정 | 소규모 실제 CSV 점검, 오류·레이아웃 정리, 시연·보고서 |

## 남은 4주 배분

| 기간 | 한 가지 중심 목표 | 일정이 부족할 때 줄일 부분 |
| --- | --- | --- |
| 1주차 | 이번 CSV 화면에서 기존 계산 코어까지 한 흐름으로 연결 | 추가 계산 종류·새 디자인 제외 |
| 2주차 | 최소 수치 비교와 계산 근거 표시 | 자연어 자동 추출·새 GPT 호출 제외 |
| 3주차 | 실제로 처음 쓰는 사람과 소수 CSV로 사용성·오류 점검 | 큰 데이터셋·모델 비교·새 연구 실험 제외 |
| 4주차 | 오류 수정, 문구·레이아웃 정리, 발표 자료와 최종 데모 | 기능 추가 전면 동결 |

웹 검색·실시간 GPT 분석은 기존 자산으로 남기되 이 마감의 필수 경로에 넣지 않는다. 유료 호출·배포는 지금 승인된 작업이 아니며 별도 결정이 필요하다. 사용자별 CSV 장기 보관, DB migration, SDK, 범용 Agent 연결, 고급 통계검정, 새로운 예측 모델 학습은 이번 4주 범위에서 제외한다.

## 마무리 기준

- 핵심 시나리오 3개: 합계, 평균, 서로 겹치지 않는 기준과 현재 범위의 증감률.
- 잘못된 열·누락값·0인 기준·숫자 형식 오류를 조용히 계산하지 않는다.
- 표시한 수치의 자료·단위·범위·계산식을 다시 확인할 수 있다.
- 조건이 바뀌면 이전 계산 결과와 확인 상태를 유지하지 않는다.
- 파일이 어디로 전달되고 보관되는지 화면에서 알 수 있다.
- 새 기능보다 실제 사용 중 발견한 오류와 마감 완성도를 우선한다.

진행률은 각 milestone의 완료 항목을 기준으로 보고한다. **이번 입력·조건 확인 milestone은 100%**이며, 이것이 통합 제품 전체 완료를 뜻하지 않는다. 통합 제품 전체의 임의 퍼센트보다 위 작업의 완료 여부와 남은 주차로 마감을 관리한다.

다음 milestone은 **기존 계산 코어를 확정된 CSV·조건에 연결하고 결과·계산식·사용한 행을 표시하는 작업 하나**로 제한한다.
